# Maze Hunt Pacman

**One-sentence introduction:** Maze Hunt Pacman is a Java console game where one or two players guide Pacman through seeded maze layouts, collect power-up food, defeat monsters, and compete for the highest score.

## Overview

This project is a terminal-based Pacman-style maze game written in Java. The game starts from the command line, generates a maze from the dimensions and random seed you provide, and lets players move Pacman with keyboard commands until the game is won, lost, or paused.

The codebase currently supports:

- Single-player and two-player modes
- Three maze layouts: lower triangle, upper triangle, and horizontal wall maze
- Seeded random placement for monsters and special food
- Pause and resume during a game
- Score tracking for completed games
- End-of-game comparison for multiplayer rounds

## Project Structure

- `src/GameEngine.java`: main entrypoint, menu flow, mode selection, game lifecycle, and score viewing
- `src/Maze.java`: maze generation, entity placement, movement rules, collision handling, and score calculation
- `src/LocationGenerator.java`: seeded random position generation
- `src/ScoreBoard.java`: placeholder class; scoreboard output is currently handled inside `GameEngine`
- `out/production/`: compiled class output from the IDE/build process

## How The Game Works

When the program starts, it expects three command-line arguments:

```bash
java -cp src GameEngine <mazeLength> <mazeWidth> <seed>
```

Example:

```bash
java -cp src GameEngine 12 10 42
```

Argument meanings:

- `mazeLength`: maze width in columns
- `mazeWidth`: maze height in rows
- `seed`: random seed used for deterministic monster and food placement

After launch, the player can:

- Choose single-player or multiplayer
- Create one of three maze types
- Start a new game
- Resume a paused game
- View scores for completed games
- Exit back to the player selection menu

## Controls

During gameplay, movement is keyboard-driven:

- `W`: move up
- `A`: move left
- `S`: move down
- `D`: move right
- `Q`: pause and save the current game

## Maze Elements

- `P`: Pacman
- `#`: boundary
- `-`: wall sections generated by the selected maze type
- `.`: open path
- `*`: special food
- Monster positions are generated from the four monster types defined in code: red, blue, green, and yellow

## Scoring Rules

The scoring logic is implemented in `Maze.java` and follows these rules:

- `+5` for each special food eaten
- `+10` for each monster killed
- `-0.5` when Pacman hits a wall or boundary
- `-0.25` for each move
- `+20` bonus if all four monsters are defeated before Pacman dies

If Pacman meets a monster without available super power, the game ends immediately.

## Multiplayer Behavior

In multiplayer mode, both players receive the same maze type, dimensions, and seed. Player 1 plays first, then Player 2. Once both games are complete, the program compares scores and announces the winner.

## Build And Run

Compile:

```bash
javac src/*.java
```

Run:

```bash
java -cp src GameEngine 12 10 42
```

This project does not currently include an automated test suite or build tool such as Maven or Gradle.

## Notes On The Current Implementation

- Input validation in `GameEngine` expects exactly three positive integer-style arguments
- Score history is stored in memory for the current program run only
- `ScoreBoard.java` is not yet implemented as a separate scoreboard abstraction
- The source still contains some TODO comments and opportunities for refactoring, documentation, and stronger validation
